# Tarot

> <sub>This document was generated by Anthropic's Claude Fable 5.2.</sub>

This is a script package for Miyu. It provides one tool, `tarot`. It draws tarot cards into a spread and returns each card's position, whether it is upright or reversed, and its keywords. The tool only deals the cards; the reading is left to the AI.

| Parameter | Description |
|---|---|
| `spread` | The spread: `single` (1 card), `three_card` (past/present/future), `yes_no` (for/against/overall), `relationship` (4 cards), `celtic_cross` (Celtic Cross, 10 cards), `custom`. The default is `single`; if `positions` is given without a spread, it is treated as `custom` |
| `positions` | For `custom` only: position names, or `{name, hint}`, at most 78 |
| `question` | What you are asking about; the tool returns it unchanged and it does not affect the draw |
| `reversal` | The probability that each card is reversed, 0–1, default 0.3; 0 turns reversals off |
| `keywords` | Whether to include keywords; included by default |

The full deck of 78 cards is shuffled once and dealt from the top, so no card repeats within one draw. The random numbers come from the system entropy source, and **there is deliberately no seed parameter**: the AI cannot pick a seed to pick the result.

The declaration at the top of the script says `Clicall: no`, so the AI can only call this tool directly and cannot redraw again and again through `miyu call` inside a command; every draw appears as its own entry on the timeline.
